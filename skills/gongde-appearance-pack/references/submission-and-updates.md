# 安装、投稿与版本更新

## 安装

仓库：https://github.com/Mr-shanqiu/gongde-appearance-pack

支持 Skills CLI 的环境可以运行：

```sh
npx skills add Mr-shanqiu/gongde-appearance-pack --skill gongde-appearance-pack
```

安装器会询问目标 Agent 与安装范围。也可请自己的 Agent 从仓库的 `skills/gongde-appearance-pack` 目录安装。其他环境可从 Releases 下载 ZIP，解压后按 Agent 的技能目录说明放置。安装一次后可重复使用，制作工具需要 Node.js 18+。不保证所有 Agent 都支持自动安装。

通过同一个仓库的版本标签和 Releases 获取更新。主动检查版本后选择更新；当前工具没有后台轮询或自动更新程序，不在制作命令中下载并执行远程代码。更新 Skill 不应覆盖作者作品或已安装形象。
